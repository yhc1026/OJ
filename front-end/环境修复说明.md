# 前端环境说明

## 现在可以「不用 Python」

当前 **`启动前端.bat`** 已改为用 **PowerShell**（`serve-static.ps1`）提供页面，**不必安装 Python / Node**。  
若仍失败，再往下看历史诊断与修复方式。

---

# 前端启动失败：根据你的诊断结果（旧版说明）

## 问题原因（已确定）

- 系统里有 **`py.exe`**（Python 启动器），但它要去启动 **`D:\Python\python.exe`**。
- 这个 **`D:\Python\python.exe` 已经不可用**（删过、换过盘、装坏、路径不对等），所以报错：  
  `Unable to create process using 'D:\Python\python.exe ...'`
- 同时 **`python` 不在 PATH**，**也没装 Node**，所以 `启动前端.bat` 没法起静态服务。

**端口没问题**：8765 等是空的；9000 是网关，正常。

---

## 推荐做法（二选一）

### 方案 A：重装 Python（推荐，一条龙）

1. 打开：<https://www.python.org/downloads/>  
2. 下载 **Windows installer（64-bit）**。  
3. 安装时**务必勾选**：**Add python.exe to PATH**。  
4. 安装目录可保持默认（例如 `C:\Users\你\AppData\Local\Programs\Python\Python3xx`），**不要**再指到已坏的 `D:\Python`（除非你确认要修那里）。  
5. **关掉所有已开的 CMD/PowerShell**，再双击 **`启动前端.bat`**。

若仍指向旧路径，可看下面「清理 py 启动器配置」。

### 方案 B：安装 Node.js（不用 Python）

1. 打开：<https://nodejs.org/> 安装 **LTS**。  
2. 安装时勾选 **Add to PATH**。  
3. **重新打开**命令行窗口，再双击 **`启动前端.bat`**（脚本会自动用 `npx serve`）。

---

## 可选：清理错误的 `py` 配置

若重装后 **`py -3` 仍去找 D:\Python**，可检查这两个文件（用记事本打开）：

- `%LOCALAPPDATA%\py.ini`  
  （完整路径类似：`C:\Users\你的用户名\AppData\Local\py.ini`）
- `C:\Windows\py.ini`（若有）

里面若有指向 **`D:\Python\python.exe`** 的项，改成**新装的 python.exe 全路径**，或**删掉整段**让启动器自动找。

---

## 装好后自测

在 **front-end** 文件夹打开 **CMD**，执行：

```bat
py -3 --version
```

或：

```bat
python --version
```

能显示 `Python 3.x.x` 即正常，再运行 **`启动前端.bat`**，浏览器打开：

**http://127.0.0.1:8765/**
